# 🚀 CodeBench — C++ Judge

A lightweight **LeetCode-style C++ practice judge** that runs completely in the browser. No backend, compiler, or installation required.

## ✨ Features

* 🧩 18 C++ DSA problems
* 📝 LeetCode-style descriptions, examples & constraints
* ▶️ **Run** with 2 sample test cases
* 🚀 **Submit** with 5–7 hidden test cases
* ✅ Automatic Accepted/Failed status
* 💾 Saves code & progress automatically
* 🌐 100% client-side
* 📱 Simple browser-based interface

## 🛠️ Supported C++

Supports:

```text
int, double, bool, char, string
vector<T>
loops, conditions, recursion
push_back, size, sort, swap
substr, to_string, min, max
```

Not supported:

```text
map, set, pair, pointers, templates
```

## 🚀 Usage

1. Open `cpp-judge.html`
2. Select a problem
3. Write your C++ solution
4. Click **Run**
5. Click **Submit**

No installation required.

## ⚠️ Note

CodeBench uses a custom **C++ → JavaScript transpiler**, not a real C++ compiler. It supports only the C++ features required by the included problems.
